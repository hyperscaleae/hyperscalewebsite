# HyperScale Studio

Open `Open HyperScale Dashboard.cmd` in the Dashboard folder. The app opens in your browser and runs locally on this computer at http://127.0.0.1:4587/dashboard.

## Start a client project

1. Open Settings and enter your legal business name, email, address and payment instructions. These are intentionally blank. Enable draft VAT calculations only when your registration and tax treatment have been confirmed.
2. Choose Clients and New client. Enter the brief and contact information.
3. Fill Project with the agreed scope, deliverables, acceptance criteria, timeline, exclusions, fees and revisions.
4. Create a Proposal, review it, and download its editable HTML copy or print it to PDF.
5. Prepare the Agreement as a draft for legal review. The app does not capture signatures or record acceptance.
6. Enter invoice items, dates, a unique invoice number and payments. Preview and check the invoice before issue. The app calculates draft amounts in AED; it is not an accounting or tax filing system.
7. Prepare the Welcome pack. Use Portal to select the tasks and links you want the client to see, then export the Client portal snapshot.
8. Share the website feedback form after delivery. Import downloaded responses or record feedback in the selected client.

## Your files

- Brand Assets: the current HyperScale logo and symbol.
- Portfolio Assets: the approved local project logos and previews. Client marks remain their owners' property.
- Editable Templates: seven self-contained HTML documents. Open a file, edit the document text, then use Save edited copy. Print / Save PDF creates a print-ready version. Printed invoice totals will not recalculate when you directly edit the HTML; use the dashboard for calculations.
- Print Materials: individual blank reference PDFs and a combined workflow pack. Replace bracketed fields using the editable templates before giving documents to clients.
- Company Profile: services overview, customer acquisition plan and an editable company profile.
- Dashboard: a local copy of the application, local server and launcher.
- Backups: a folder for downloaded JSON workspace backups. Your browser controls where downloads are saved; move them here if appropriate.

## Where records are saved

The dashboard saves records in local storage in this browser profile. It has no account, cloud database or cross-device sync. Use your normal private browser profile, not incognito. Clearing browser data removes these records. The online website dashboard and the Desktop dashboard have separate browser storage because they are different origins.

Download a backup after meaningful changes. Settings lets you restore a validated HyperScale JSON backup; review the replacement confirmation before restoring. Backups include all client details. Keep them in private storage. No real client records are included in this package.

## Portal and production setup

Client portal exports are read-only snapshots containing one client's shared scope, schedule, update, selected tasks and links. They exclude internal notes, billing and other clients. Review the file and linked-file permissions before sharing. Files do not update automatically. This is not a secure online portal with logins, payments, uploads or electronic signatures.

A shared online workspace needs server hosting, authentication, role-based access, database backups and secure file storage. Static Hostinger preview hosting does not run these services. Email delivery also requires a configured provider and a real delivery test.

Invoices remain drafts until your business identity and tax details are ready. Agreement templates need appropriate legal review and completed commercial terms. UAE invoice reference: https://tax.gov.ae/Datafolder/Files/Pdf/2023/Knowledge%20Center%20Page/VAT11%20-%20Tax%20invoices%20En.pdf

The launcher uses the Node runtime already available on this computer. This package is not a Windows installer; another computer will need Node and an updated launcher path. The local server binds only to this computer. Closing the browser leaves the local server running; it can be reused the next time you open the launcher.
