# HyperScale Studio

Open **Open HyperScale Dashboard.cmd** in this folder. Your private dashboard runs at http://127.0.0.1:4590/dashboard. Create your agency account on first use.

## Start a project

1. Fill Settings with your business details. Legal name, contact, tax and bank fields remain editable and blank.
2. Create a project, add its scope, schedule, tasks and client update. Save changes into the project.
3. In Documents preview a proposal, agreement, invoice or welcome pack. Download a printable copy or publish a version to the portal.
4. Create a client account in Settings. Once hosted, clients use `/portal` to share files, send messages, add requests, track milestones and review documents. No invitation is automatically sent.
5. Time tracks billable and internal work; Expenses records costs; Templates creates repeatable projects.

## Files

Brand Assets and Portfolio Assets preserve the current assets. Company Profile contains services and acquisition materials. Editable Templates and Print Materials contain the earlier editable HTML/reference PDF copies; the new dashboard generates project-specific copies. Inquiry is on the public website only, outside the dashboard template library. The earlier portal HTML file is a legacy snapshot, not the new shared portal.

## Storage and hosting

The private server stores encrypted records and files in `%USERPROFILE%\.hyperscale-portal`, outside the website folder. Settings imports previous browser client records without deleting their original copy. Use the same browser that held the old records. Company settings should be entered in the new workspace.

The Desktop server works on this computer only. The static Hostinger preview cannot serve accounts or private uploads. The prepared Node deployment needs a hosting account, persistent disk, HTTPS origin and private environment configuration before remote clients can connect. See **Dashboard / PORTAL HOSTING.md** for complete setup and backup steps. A paid Render configuration is included as an option; no hosting was purchased.

Keep complete backups of the private data folder and matching encryption key. Dashboard exports are record-only copies and exclude file contents and accounts. Client approvals record the reviewed version, name and timestamp; verified electronic signatures and payment reconciliation are not implemented. Review agreements and invoice details before issuing them.
